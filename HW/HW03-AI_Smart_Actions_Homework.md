# 🏠 Home Task 03: GitHub Copilot – AI Smart Actions

## 🎯 Goal
Practice using **GitHub Copilot AI Smart Actions** directly in your IDE to speed up common development tasks such as commits, documentation, testing, reviews, and debugging. Reflect on how these actions can improve your daily workflow.

---

## 📋 Prerequisites
- GitHub Copilot enabled in your IDE  
- Visual Studio Code recommended  
- GitHub Pull Requests extension installed  
- Any existing project or a small demo project  

---

## 🧩 Part 1. Commit & Pull Request Automation
**Task**
- Make a small code change in your project.
- Use Copilot to generate:
  - Commit message
  - Pull Request title and description

**Deliver**
- Generated commit message  
- Generated PR title and description  
- Short note: Was the output accurate and useful?  

---

## 🧩 Part 2. Code Quality with AI Smart Actions
Choose **any two** tasks below:

- Resolve a merge conflict using AI  
- Rename symbols using AI suggestions  
- Implement a TODO comment via Copilot agent  
- Generate documentation for a code file  
- Generate tests using smart actions  
- Fix a coding or test failure using AI  
- Explain a complex code block with Copilot  

**Deliver**
- Which AI Smart Action you used  
- What problem it solved  
- Before vs after result  

---

## 🧩 Part 3. Markdown & Documentation
**Task**
- Open a Markdown file with images.
- Use Copilot to:
  - Generate alt text
  - Refine existing alt text (if present)

**Deliver**
- Example of generated or refined alt text  
- Short reflection on accessibility and quality  

---

## 🧩 Part 4. AI-Assisted Review & Search
**Task**
Perform **one** of the following:

- Run AI code review on a code block or Pull Request  
- Use semantic search to find code or documentation by meaning  

**Deliver**
- Screenshot or short description of Copilot feedback or search result  
- Was semantic search better than keyword search?  

---

## 🧩 Part 5. Reflection
Answer briefly:

- Which AI Smart Action was the most useful?  
- Where did Copilot save you the most time?  
- Where did you still need manual intervention?  

---

## 📦 Submission Format
- Short Markdown or text document  
- Bullet points are enough  
- Screenshots optional but welcome  

---

  - Code review
